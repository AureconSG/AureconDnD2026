# Aurecon D&D 2026 invitation

This package is ready for GitHub Pages. It uses plain HTML, CSS, and JavaScript, so no installation or build step is needed.

## Upload to GitHub

1. Create a new **public** GitHub repository.
2. Select **Add file → Upload files**.
3. Upload the **contents of this folder**. Keep `index.html` at the top level.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select `main` and `/ (root)`, then press **Save**.
7. GitHub will display your website link when publishing finishes.

## Included

- Animated envelope and invitation card
- Aurecon logos and colour palette
- Cinzel font
- Shortened clue video (first half of the supplied video)
- Live countdown on the landing page and under the video
- Responsive desktop and mobile layout

All links are relative, so the files work from a GitHub project URL such as `https://username.github.io/repository-name/`.
